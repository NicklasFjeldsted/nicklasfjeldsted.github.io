# M.V.O.

Website for a masonry company, with an admin page so the masons can maintain the content themselves.

- `murerfirmaet-M.V.O/` — Angular frontend (public site and `/admin`)
- `backend/` — .NET 9 API with MySQL; see [backend/README.md](backend/README.md)
- `docs/tasks/` — task specifications; see [docs/tasks/README.md](docs/tasks/README.md)
